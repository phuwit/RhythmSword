# RhythmSword

extremely good clone of beatsaber

## Installing beatmaps
1. source beatmap zip file. https://beatsaver.com/ is a good choice.
2. extract the beatmap file into a folder. so that the contents of the folder would contains `Info.dat` something like `{song_name}/Info.dat`
3. copy the beatmap folder to
    - Windows: `C:\Users\{username}\AppData\LocalLow\John Oculus\RhythmSword\Songs`
    - Android/Quest: `{Quest}/Internal Storage/Android/data/com.johnoculus.rhythmsword/files/Songs`
4. reload the song list by entering an existing song, then return to the main menu. or just restart the app. whichever you prefer.
